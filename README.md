## 🧩 Featured Engineering Projects

### 🤖 AI & RAG Systems

**1. Travel Agent Recommendation — Full-Stack RAG Engineer**

Built a full-stack multi-agent travel planning application combining LLM orchestration, external tools, and human approval workflows.

**Technologies:** Next.js, TypeScript, Python, FastAPI, PostgreSQL, LangChain, LangGraph, MCP, LangSmith, RAGAS.

Key engineering contributions:
- Developed multi-agent travel planning workflows using LangGraph.
- Integrated MCP tools for aviation, web research, and weather information.
- Implemented Human-in-the-Loop (HITL) approval workflows.
- Built JWT authentication and API rate-limiting mechanisms.
- Implemented context-length guardrails, model fallback routing, and LLM evaluation.
- Integrated LangSmith tracing and RAGAS quality metrics.

**2. Graphical RAG — Full-Stack RAG Engineer**

Developed a Graph RAG application using graph-based retrieval and LLM context grounding.

**Technologies:** Next.js, TypeScript, Python, FastAPI, Neo4j, LangChain, LangGraph, LangSmith, RAGAS.

Key engineering contributions:
- Designed entity-relationship retrieval using Neo4j and Cypher.
- Orchestrated graph retrieval and LLM workflows using LangGraph.
- Implemented multi-LLM failover between OpenAI and Groq.
- Integrated LangSmith observability and RAGAS evaluation.
- Evaluated Faithfulness, Answer Relevancy, Precision, and Recall.
